# YTdw
 A Python Script to download Youtube Videos
Dependencies: PyTube, ffmpeg-pytho

In order to use this program you need to follow theese steps, assuming you already have python installed.
1) Install ffmpeg on your PC (https://www.youtube.com/watch?v=K7znsMo_48I)
2) Install python dependencies 'Pytubefix' and 'ffmpeg-python'
